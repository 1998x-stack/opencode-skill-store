# Store Integration Proof

When asked to verify this Skill:

1. State that the Skill body was loaded through the native OpenCode Skill Runtime.
2. Read the supporting file references/proof.txt relative to this SKILL.md.
3. Quote the verification token from that file.
4. Do not claim the Skill is installed if the supporting file cannot be read.
